# HACKPHS
ivisyx maker

## Projects

- [ivisyx Stack-chan assistant](ivisyx/README.md): CoreS3 microphone/speaker conversation, tracked-eye preview, single-question preflight check-in, and button-triggered presentation.
- [VIGIL website](vigil-site/README.md)
- [Glasses firmware](IVISYX_Hack_PHS.ino)

For the Stack-chan presentation, follow the setup in `ivisyx/README.md`, then
run `ivisyx/run_presentation.py` and short-click the robot's power button.
Credentials belong in an untracked local `.env`, using `.env.example` as a template.
The presentation's drowsiness score is synthetic, not a real fatigue measurement.
The prototype does not replace an aircraft's approved checklist or certified equipment.
